# Paper Trader (plain Java, no build tool)

Console version of the practice trading app. Author: Austin Lantz

## Run (Git Bash)
```
export FINNHUB_API_KEY=your_key_here
javac PaperTrader.java
java PaperTrader
```
Or run without a separate compile step: `java PaperTrader.java`

Get a free API key at https://finnhub.io
